Stitch 生成提示词：鲜果记 - 精品生鲜小程序（用户端）
项目概述
为一家名为"鲜果记"的单商户精品生鲜小程序生成完整的用户端 UI/UX 设计稿。这是一家个人经营的水果蔬菜店铺，非多商户平台，因此 UI 中不应出现商家切换、店铺列表、跨店凑单等多商户元素。
所有页面文字内容请使用简体中文。
一、品牌与视觉调性
品牌定位：精品生鲜个人店铺，强调品质感、新鲜感、有温度的个人经营。
视觉风格参考：盒马、每日优鲜的干净留白风，避免多多买菜那种大红大绿的低价压迫感。
设计系统要求：

主色：自然绿 #2E7D32（品牌色，用于按钮、强调、Tab 选中态）
辅助色：嫩芽绿 #8BC34A（用于标签、进度条）
中性色：背景 #FAFAFA，卡片白 #FFFFFF，主文字 #212121，次要文字 #757575，分隔线 #EEEEEE
价格红：#E53935（仅用于划线原价旁的实付价、优惠金额）
字体：苹方 / PingFang SC，标题 Semibold，正文 Regular，价格数字使用 Medium
圆角：卡片 12px，按钮 24px（胶囊形），输入框 8px
阴影：极轻，0 2px 8px rgba(0,0,0,0.04)
图标：线性图标为主，2px 描边，避免卡通风格
图片：商品图采用纯白或浅米色背景的高清静物图，色彩鲜艳突出新鲜感
间距：基础栅格 4px，卡片间距 12px，板块间距 24px

整体感受：干净、留白多、品质感、年轻化，让用户感到"这家店东西很新鲜很讲究"。
二、关键产品规则（务必遵守）

单商户：全程不出现"店铺"切换、多商家分组等概念。
商品规格：按固定规格销售（如"500g装"、"1kg装"、"2斤装"），不做按实际称重结算，所以订单流程中不需要显示"实际重量""多退少补"等环节。
自提/配送选择时机：在结算页选择，不在首页顶部做选择器（区别于多多买菜）。
拼团：在商品详情页以"单独购买 / 发起拼团"两个并列价格 Tab 呈现，拼团价更低，支持分享邀请。
店主推荐：首页设"店主推荐"模块，体现个人店铺的温度感（这是单商户区别于平台的核心特色），但不需要店主头像、故事页等其他个人化模块。
价格展示规则：凡有优惠处，必须同时显示划线原价 + 实付价，让优惠感清晰但不刺眼。
不做秒杀功能：本项目不包含限时秒杀玩法，所有页面均不出现秒杀入口、秒杀专场、倒计时抢购等元素。

三、页面清单（共 12 类页面，请全部生成）
1. 启动页 + 登录页

启动页：品牌 Logo "鲜果记" 居中，副标题"新鲜直达，每日精选"，背景为浅绿色调的水果蔬菜插画或静物图，干净简洁。
登录页：白底，顶部品牌 Logo，中部手机号输入框 + 验证码按钮，主按钮"登录"（品牌绿），下方"微信一键登录"图标按钮，底部隐私协议勾选与文案。极简风格。

2. 首页
从上至下依次为：

顶部状态栏 + 搜索栏：圆角搜索框，placeholder "搜索新鲜果蔬"，右侧消息铃铛图标
分类快捷入口：横向排列 8 个左右的分类图标（叶菜、水果、根茎、菌菇、肉禽蛋、水产、豆制品、烘焙），图标 + 文字
轮播 Banner：1 个全宽轮播位，展示当季主题（如"夏日西瓜节"、"新会员立减 10 元"）
优惠券领取区：横向滑动卡片，展示 3 张可领优惠券（如"满 39 减 5"、"满 69 减 10"），右侧"立即领取"按钮
拼团专区入口：横向通栏卡片，标题"🤝 好货拼着买"+ 副标题"和邻居一起省"，右侧"去拼团 ›"，下方横向滑动展示 3-4 个热门拼团商品小卡（商品图、拼团价、"X 人团"标签）
店主推荐模块：标题"🌿 店主推荐"+ 副标题"今日新到，亲自挑选"，下方双列瀑布流展示 4-6 个商品，商品卡含图、名称、规格（"500g"）、划线原价、实价、"加购"圆形按钮
今日精选：双列瀑布流商品列表，与店主推荐相同卡片样式，可无限下滑
底部 Tab Bar：5 个 Tab——首页、分类、购物车（带角标）、订单、我的；选中态品牌绿，未选中态灰色

3. 商品分类页

顶部搜索栏（与首页一致）
左侧一级分类垂直列表（占屏幕宽度约 25%），选中项左侧有品牌绿竖条 + 浅绿底色
右侧对应商品网格区，顶部展示二级分类横向 Tab（如水果下分：当季鲜果、进口水果、礼盒装），下方双列商品卡片，样式同首页

4. 商品详情页
从上至下：

商品图轮播：全屏宽，4:3 比例，底部小圆点指示器
价格区域：左上"单独购买 / 发起拼团"两个 Tab 切换，单独购买 Tab 下显示实价（大号）+ 划线原价 + 省 ¥X 标签；拼团 Tab 下显示拼团价（更低）+ 单买价对比 + "已拼 X 件" + 分享按钮"邀请好友拼团"
商品名称 + 简短卖点：如"阳光玫瑰葡萄 / 当日新摘 现剪现发"
规格选择：标签按钮组，如"500g装 / 1kg装 / 2kg礼盒装"，库存紧张时显示"仅剩 3 件"
满减提示条：浅绿底，"🎁 本单满 39 元减 5 元，还差 ¥12"
配送信息：图标 + 文字，"支持同城配送 / 自提点自取，下单后次日送达"
商品详情图文区：标题"商品介绍"，下方长图文（占位为多张商品细节图 + 描述段落）
评价摘要：标题"用户评价（128）"+ 总体评分 4.8★ + 2-3 条评价缩略，右侧"查看全部"
底部固定操作栏：左侧客服图标、购物车图标（带角标），右侧"加入购物车"（次要按钮，浅绿描边）+ "立即购买"（主按钮，品牌绿填充）；拼团 Tab 下，右侧按钮变为"发起拼团 ¥XX.X"

5. 购物车页

顶部标题"购物车"+ 右上"管理"
商品列表（不按商家分组，因为单商户），每行：左侧勾选框、商品图、名称、规格、单价、右下数量加减器
满减进度提示条：浅绿底，"再买 ¥12 即可减 5 元"
底部固定结算栏：左侧全选勾选框 + "合计 ¥XX.X" + 已优惠 ¥X，右侧"结算（3）"主按钮
空购物车状态：居中插画 + 文案"购物车还是空的"+ "去逛逛"按钮

6. 结算/确认订单页

配送方式选择模块（页面顶部，必须显眼）：两个并排单选大卡片

同城配送：图标 + "同城配送"+ 默认地址（可点击切换）+ 配送时段选择（今日 18:00-20:00 / 明日上午 等）
自提：图标 + "到店自提"+ 默认自提点（可点击切换）+ 自提时段


商品清单（不可改数量），每行：商品图、名称、规格、单价 × 数量
优惠券选择：单行入口，右侧显示"可用 2 张 ›"，点击进入选择列表
备注输入框：placeholder "想对店主说点什么？（选填）"
价格明细：商品总价、满减优惠（绿色 -¥5）、优惠券抵扣（绿色 -¥5）、配送费（满 39 包邮则显示"已减免"）、实付款（醒目）
底部固定栏：左侧"实付 ¥XX.X"，右侧"提交订单"主按钮

7. 支付结果页

成功页：顶部大号绿色对勾图标，"支付成功"，付款金额，下方两个并排按钮"查看订单"+"继续购物"，再下方推荐商品横向滑动列表
失败页：红色感叹号图标，"支付失败"，原因提示文案，"重新支付"主按钮 + "返回购物车"次按钮

8. 订单列表页 + 订单详情页
订单列表页：

顶部 Tab：全部、待付款、待发货/待自提、配送中、已完成、退款/售后
订单卡片：订单号 + 状态标签（右上）+ 商品缩略图横向排列（最多显示 3 个 + "+N"）+ 共 X 件商品 + 实付金额 + 底部操作按钮（按状态变化：去支付 / 提醒发货 / 查看物流 / 确认收货 / 去评价 / 再来一单）

订单详情页：

顶部状态卡：当前状态大字（如"配送中"）+ 配送进度条（4 步：商家已接单 → 已出库 → 配送中 → 已送达）；自提订单显示自提码（大号数字）+ 自提点地址 + 地图缩略图入口
配送中状态：显示骑手实时轨迹地图（占位即可）+ 骑手姓名电话
收货/自提信息卡
商品清单
价格明细（同结算页结构）
订单信息：订单号、下单时间、支付时间、支付方式（带"复制"按钮）
底部操作栏：联系客服 + 主操作按钮

9. 评价模块
评价提交页：

顶部商品小图 + 名称
星级评分（5 颗星，点击交互）
文字输入框（多行，placeholder "分享你的购买体验吧～"）
上传图片区（最多 3 张，含 + 占位）
匿名评价勾选项
底部"提交评价"主按钮

评价查看页（从商品详情页或订单详情页进入）：

顶部评分总览：4.8★ + 总评数 + 各维度评分条（新鲜度、性价比、包装）
筛选 Tab：全部、有图、好评、中评、差评
评价列表：用户头像 + 昵称（部分隐藏）+ 星级 + 评价文字 + 图片 + 规格信息 + 时间

10. 个人中心页

顶部头像 + 昵称 + 右上设置图标，背景浅绿渐变
资产卡片区：横向 4 格——优惠券 / 我的拼团 / 收藏 / 足迹，每格显示数量
我的订单入口：标题 + "全部订单 ›"，下方 5 个状态图标横向（待付款、待发货、待收货、待评价、退款/售后）
常用功能列表：地址管理、自提点管理、消息中心、客服中心、关于鲜果记
底部 Tab Bar

11. 地址管理 / 自提点管理
地址管理：

列表展示已保存地址：收货人、电话、详细地址、"默认"标签，右侧编辑图标
滑动可显示删除按钮
底部固定"+ 新增地址"按钮
新增地址表单：收货人、手机号、所在地区（省市区选择）、详细地址、标签（家/公司/学校）、设为默认开关

自提点管理：类似结构，含地图选点页——上方地图（带定位中心点和附近自提点 Marker）+ 下方自提点列表（名称、距离、营业时间）
12. 拼团活动页 + 搜索页 + 消息中心
拼团活动页：

顶部 Banner "好货拼着买，便宜又新鲜"
玩法说明小卡：3 步图解（开团 → 邀请 → 拼成）
进行中拼团商品列表：每个商品卡显示商品图、名称、原价 / 拼团价、"X 人团" 标签、"X 人正在拼"、"去开团"按钮

搜索页：

顶部搜索框（聚焦态）+ 取消
搜索历史标签云（可清空）
热门搜索（带 🔥 图标）
输入时显示联想词列表
搜索结果页：顶部排序 Tab（综合、销量、价格升降序）+ 筛选按钮，下方双列商品瀑布流
无结果状态：插画 + "没有找到相关商品"+ 推荐商品

消息中心：

Tab 或列表：系统通知、订单消息、优惠活动、拼团动态
每条消息：图标、标题、摘要、时间、未读红点

四、全局状态要求
请为以下场景生成对应的状态页：

空状态：购物车空、订单空、优惠券空、搜索无结果（统一插画风格 + 引导按钮）
加载状态：骨架屏（商品卡片占位）
错误状态：网络异常 + "重新加载"按钮

提供页面间跳转流程图，标注关键交互热区
所有页面内的文字、按钮标签、占位文案均使用简体中文
视觉风格务必体现"精品生鲜 + 个人店铺温度感 + 年轻化品质感"，避免低价压迫感与平台化冷感
